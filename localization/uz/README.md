# Kirish

Dizayn naqshlari (Design Patterns) — dasturchi va dasturiy ta'minot muhandislari ilova yoki tizimlarni loyihalashda tez-tez uchraydigan muammolarni hal qilish uchun foydalaniladigan eng yaxshi va sinalgan usullardir.

Dizayn naqshlari amaliyotda sinovdan o'tgan tamoyillar bo'lgani uchun, ular dasturiy ta'minotni ishlab chiqish jarayonini sezilarli darajada tezlashtiradi.

Dizayn naqshlaridan qayta foydalanish kelajakda paydo bo'lishi mumkin bo'lgan yashirin muammolarning oldini oladi, shuningdek, kodning o'qilishini (readability) va arxitektura tushunarliligini oshiradi.

# Boshlash

Ushbu loyiha Java tilida yozilgan Dizayn Naqshlarini namoyish etadi. Yechimlar ochiq kodli hamjamiyatning tajribali dasturchilari va dasturiy ta'minot me'morlari (architects) tomonidan ishlab chiqilgan va sinovdan o'tkazilgan.

Har bir dizayn naqshini uning batafsil tavsifi hamda manba kodlarini ko'rish orqali o'rganishingiz mumkin. Manba kodlari tushunarli izohlar bilan ta'minlangan bo'lib, muayyan naqshni qanday qo'llash bo'yicha amaliy darslik vazifasini o'taydi.

Loyiha bilan ishlashni boshlashdan oldin asosiy [Dasturiy Ta'minot Loyihalash Tamoyillari](https://java-design-patterns.com/principles/) bilan tanishib chiqish tavsiya etiladi.

Asosiy tamoyillar:
- [KISS](https://en.wikipedia.org/wiki/KISS_principle) (Keep It Simple, Stupid)
- [YAGNI](https://en.wikipedia.org/wiki/You_aren%27t_gonna_need_it) (You Aren't Gonna Need It)
- [Do The Simplest Thing That Could Possibly Work](https://learning.oreilly.com/library/view/extreme-programming-pocket/9781449399849/ch17.html)

Ushbu tushunchalar bilan tanishganingizdan so'ng, [mavjud dizayn naqshlarini](https://java-design-patterns.com/patterns/) chuqur o'rganishni boshlashingiz mumkin.
